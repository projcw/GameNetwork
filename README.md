# 애니멀 파이터 서버 명세서

> 게임서버프로그래밍 팀 프로젝트  
> 게임 진행 중 발생하는 9가지 주요 상황에서 서버가 담당해야 할 기능을 정리한다.

## 1. 게임을 켰다

- 로그인 및 인증 처리
- 4인 매칭 대기열 등록
- 참가자 목록 및 준비 상태 동기화

## 2. 친구랑 같이 하고 싶다

- 초대 코드 또는 링크 생성 후 같은 방에 배정
- 남은 빈자리는 랜덤 매칭으로 자동 충원
- 파티원의 준비 상태를 실시간으로 동기화

## 3. 캐릭터를 골랐다

- 플레이어별 선택 캐릭터 정보 저장
- 중복 선택 허용 여부 판정
  - 중복 선택을 막는 경우 동시 선택 충돌 처리
- 모든 플레이어의 캐릭터 선택 완료 여부 확인
- 전원 선택 완료 시 게임 시작 트리거

## 4. 캐릭터를 움직였다

- 클라이언트의 방향키 입력을 서버가 검증
- 검증된 입력을 기반으로 최종 위치 확정
- 서버 권위(Server Authoritative) 모델 적용
- 대각선 이동 시 이동 속도 정규화
- 모든 플레이어의 위치를 매 틱(Tick)마다 브로드캐스트

## 5. 아이템을 먹었다

- 아이템 획득 여부를 서버가 거리 및 충돌을 기준으로 직접 계산
- 아이템 효과 적용
- 플레이어 버프 상태 갱신
- 획득된 아이템 제거
- 아이템 랜덤 리스폰 관리

## 6. 총알을 발사했다

- 발사 요청의 유효성 검증
  - 쿨다운 등의 조건 확인
- 투사체 생성 및 이동을 서버에서 직접 계산
- 총알 정보를 모든 플레이어에게 브로드캐스트

## 7. 총알에 맞았다

- 피격 여부를 서버에서 직접 판정
- 클라이언트의 피격 판정 결과는 신뢰하지 않음
- 데미지 계산 및 HP 갱신
- HP가 0 이하가 되면 사망 처리
- 플레이어의 탈락 순번 기록

## 8. 60초가 지났다

- 매치 타이머를 서버의 절대 시간을 기준으로 관리
- 제한 시간 종료 시 생존 플레이어 확인
- 생존자의 잔여 HP를 비교하여 최종 순위 산정

## 9. 게임이 끝났다

- 최종 순위 결과를 모든 플레이어에게 동시에 전송
- 전적 및 보상 데이터 갱신
- 매치에 사용된 리소스 정리
- 플레이어를 재매칭 대기열로 복귀 처리

# 애니멀 파이터

> 게임서버프로그래밍 팀 프로젝트 - 게임 기획 정리

탑뷰 2D 배틀로얄 슈팅 게임이다.  
최대 4인이 한 판에 참여해 60초 동안 전투하며, 킬을 기록하거나 제한 시간이 종료되었을 때 남은 체력을 기준으로 순위가 결정된다.

## 기본 게임 정보

| 항목 | 내용 |
|---|---|
| 장르 | 탑뷰 2D 배틀로얄 |
| 플레이어 | 최대 4인 (풀방) |
| 라운드 시간 | 60초 |
| 승리 조건 | 킬 또는 시간 종료 시 HP 기준 순위 |
| 이동 | 방향키 (대각선 이동 지원) |
| 공격 | 스페이스바 발사 |
| 아이템 | 4종 (미정) |
| 캐릭터 능력 | 캐릭터별 개별 구현 |


## 맵

총 3종의 맵을 구현한다.

### MAP 01 - 땅이 부서지는 맵

시간이 지날수록 바닥 타일이 하나씩 파괴된다.

- 시간이 지날수록 이동 가능한 공간 감소
- 파괴된 타일에서는 낙사 가능
- 시간이 지날수록 낙사 위험 증가
- 후반으로 갈수록 플레이어 간 전투 유도

### MAP 02 - 자기장 맵

시간이 지날수록 안전 구역이 점점 좁아지는 방식의 맵이다.

- 안전 구역이 지속적으로 축소
- 플레이어를 맵 중앙 방향으로 유도
- 외곽에 머무르는 플레이어에게 불리한 구조
- 게임 후반 교전을 자연스럽게 유도

### MAP 03 - 총알 난사 맵

맵 자체에서 환경 투사체가 날아와 플레이어를 공격한다.

- 플레이어 간 전투 외에 환경 요소가 추가됨
- 맵에서 일정한 방식 또는 랜덤하게 투사체 생성
- 투사체를 회피하면서 다른 플레이어와 전투
- 다른 맵보다 변수와 회피 요소가 많은 구조

## 아이템

아이템은 총 4종을 구현할 예정이다.

현재 구체적인 아이템 종류와 효과는 미정이며,
게임 밸런스와 캐릭터 능력을 고려하여 추후 결정한다.

## 캐릭터 능력

각 팀원이 캐릭터별 개별 능력을 구현한다.

캐릭터마다 서로 다른 능력을 가지며,
이동, 공격, 생존 등의 플레이 스타일에 차이를 주는 방향으로 설계한다.

## 현재 진행 상황

- 게임 기본 기획 정리
- 맵 3종 기획
- 아이템 4종 구현 예정
- 캐릭터별 개별 능력 구현 예정
- 서버 명세서 정리 완료
